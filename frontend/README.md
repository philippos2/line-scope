# Frontend（後続フェーズ）

このディレクトリにLineScopeのFrontendを構築する。
Backendと同じGitリポジトリで管理し、サーバサイド完成後に実装する。

方向性はPalantir AIP Analystを参考にした、LogiScopeよりリッチなUI。
AIとの対話を起点に、工場の状況・依存Graph・影響経路・参照文書などの根拠を確認し、
更新案の確認・人による承認・要求者による実行へ進める分析ワークスペースを目指す。
対話と分析結果・根拠・更新案・承認状況を関連付け、利用者が行き来できる体験として設計する。
この方向性はAIP Analystの実画面・機能を再現する要件ではなく、LineScopeの製造ドメインに合わせる。
具体的な画面・操作・frameworkは後続フェーズで要件・設計を確定する。
現在は案内文書のみで、Frontendの実装・build設定・依存packageは追加していない。

仕様の正本は[成果物一覧](../docs/deliverables.md)が指定する19文書。
