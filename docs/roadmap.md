## 現在地と残PR

- PR #263・#264・#265はmerge済み。シナリオ1の設備検索・関係図・損害額・代替提案の実装と検証を行った。
- 5174番のLLM接続は復旧し、設備コードを含む質問への実応答を確認済み。質問対象の引継ぎ・原因別エラー表示は残る。
- **PR #266は文書のみのDraft。実装着手は禁止されており、明示命令を待つ。**
- **基本構成は実装A/Bの2 PR。ドロワーをAへ含める推奨案で5〜7.5作業日、含めないA/Bで4.5〜6.5作業日。採否は判断待ち。** #266は別に数える。レビュー・CI・利用者確認の待ち時間は日数外。
- 未調査部分でAPI等の追加変更が必要なら、追加1 PRの可能性がある。現時点で必要とは確定しておらず、原因・影響・工数を報告してから判断する。

原因・修正方法の把握状況は[計画文書§1.1](design/post265-ui-correction-plan.md#11-原因と修正方法をどこまで把握しているか)に一覧化する。深掘り結果は[計画文書§9](design/post265-ui-correction-plan.md#9-深掘り調査の結果と限界)に追記済み。初期ボタンの無効条件・有効化経路と既存候補APIを確認した。承認・実行の書込と安全・保全の実データ候補表示は未検証。
