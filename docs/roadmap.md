## 継続して明示する制限

- 比較の費用・能力・安全入力はMOCK_FIXTUREであり、実設備の安全判断に使用しない。
- 単一の下流要約はサーバ生成。他の分析・複数分析・通常Readの自由説明は一般品質未受入。
- Graph到達、一段代替の構造成立、実際の停止・十分な能力・安全を混同しない。
- 過去指定は現在登録情報の期間評価であり、完全point-in-time復元ではない。
- 認証・認可、bind、Snapshot / version、Approval / Execute分離、Audit / Outbox原子性はデモでも維持する。
