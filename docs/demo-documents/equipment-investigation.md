# 設備の状態と保全資料を調べる（デモ用参考資料）

LineScopeでは、設備コードM-204またはM-208を検索し、PostgreSQLに登録された現在状態を確認する。状態は取得時点の登録情報であり、故障原因や運転許可を意味しない。

M-204の保全調査では、設備状態、保全予定、保全実績、登録された対応計画を確認する。停止の原因が登録されていなければ原因は不明として扱う。本資料は実機の点検手順や安全な復旧方法を定義しない。

下流への依存経路はNeo4jの分析結果を確認する。依存到達は影響候補を示すもので、接続先の実停止、生産能力、安全性を証明しない。

修理・交換・継続・代替の比較には、対象設備と経済・能力・安全・対応計画の正式入力、および共通の評価期間を選択する。未選択や未登録の情報を仮の数値で補わない。

業務データの変更は、変更準備、別の承認者による承認、元の依頼者による実行の順に進める。文書に記載された説明だけで承認や実行を行わない。
