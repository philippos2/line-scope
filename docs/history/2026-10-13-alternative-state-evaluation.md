# 複数対象の単一状態観測と成立評価

仕様正本ではなく、実装チェックポイントと対象機能の工程表。

正本domain-model §15.1 / §15.3 / §15.4、api-tools §17 / §20に従い、複数対象のGraph収集結果を一回のPostgreSQL状態観測で評価する内部Application処理を追加した。状態観測・検証をgraph_availabilityへ切り出し、既存の単一除外処理と共有する。SQL / DB driverはApplicationへ持ち込まない。

同じ観測時刻・正本状態集合を使って、全除外対象の一段代替を評価し、重要対象ごとに除外前／後の構造成立を返す。全除外条件を維持し、重要対象のほかの必須依存を代替で免除しない。Product / ProductionOperationには正本に代替関係がないため、完全探索時の空候補を明示する。Graph完全性と状態情報の確定性を分離し、状態欠落・過去時点・打切りは判定不能を維持する。

追加9テストと既存18テスト、実PostgreSQL / Neo4jで計27テストを実行した。状態adapterの呼出し一回、複数除外、非代替型、対象別結果、状態欠落、過去時点、探索不完全、入力facts不整合、状態観測後にRebuildが始まる最終gate拒否を検証した。構造成立は実際の運転・生産能力・安全性の保証ではない。
