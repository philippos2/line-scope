# Graph中心UI 第3段階と警告表示の修正

## 起点と原因

PR #257 merge後のmain `cf9e6e5`から着手。開発者から「前回取得した関係です。変更後の状態は再調査してください。」がどんな場合にも表示されるとの指摘を受けた。

Graphの警告が、通常の問い合わせ開始でtrueとなり任意の参照成功でfalseとなる共通`stale`を参照していた。そのため、変更していなくても問い合わせ中に警告が出て、逆に更新後でも属性取得だけで消える問題があった。前段階の検証ではこの表示条件の誤りを捉えられていなかった。

## 修正と第3段階の連動

- Graph取得時の更新世代を保持し、更新実行試行の世代と比較する。通常の問い合わせ中・失敗した参照で変更警告を出さない。
- 更新実行試行後の取得済みGraphには警告を表示し、属性取得だけでは解除しない。Graphを含む応答を受けたときに取得世代を記録する。取得中に更新があれば古い世代として保持する。
- 文言を「更新操作後の関係は未確認です。関係を再取得してください。」に変更。既存の実行試行通知は通信結果不明も考慮して実行開始時に発火するため、変更成功を断定しない。
- 実行画面から、対象設備を選び直して状態を捨てずに関係・影響を再取得できる導線と、正式入力比較へ戻る導線を追加した。
- 認証・承認・実行・Graph分析のサーバ契約は変更していない。別利用者へ接続を切り替えた場合の情報消去を維持する。
