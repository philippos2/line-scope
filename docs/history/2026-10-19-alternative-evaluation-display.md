# 代替提案の評価範囲・期間表示の修正

## 判断と範囲

開発依頼者の承認に基づき、Draft PR #265で表示だけを修正した。安全入力の自動取得・選択、代替費用の比較への反映、データ追加、インフラ稼働状態拡張は行わない。

現行の主画面は安全入力IDを空配列で送る。代替案のtotal_costはサーバ実装でnullとなり、economic_inputは不足情報に常に付く。そのため「未登録」「登録すれば解消する」とは説明しない。

## 変更

- 安全は今回入力を選択していない旨を表示する。品質・残るリスクは主表示の未確認行を除き、この版で評価対象外である旨を常時表示する。
- 不足条件はキーと安全判定に沿った文へ置き換えた。停止必須を未登録と誤表示しない。運転許可の注記と利用可能性の重複も整理した。
- 入力の期間はAsia/Tokyoの日本時間表示とし、送信値・算定値を変えない。能力入力は製品・版・期間で選び、入力コードは技術情報へ移した。
- 設計書・静的画面案・ロードマップを更新した。安全入力の選択と代替費用反映は後続候補としてのみ記録する。
