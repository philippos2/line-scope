# 一段代替を用いる除外後の構造成立

仕様正本ではなく、実装チェックポイントの記録。

正本domain-model §15.1 / §15.4に従い、評価済みの一段代替候補集合を使って、除外後の重要対象の全必須AND条件を評価する純粋計算を追加した。置換は除外された要素だけに適用し、ほかの必須条件を免除しない。SubstituteSelectionへ除外対象の型付きIDを保持し、別対象の候補評価の流用を拒否する。

除外前の必須閉包が不完全・循環ならINDETERMINATE。使用する代替評価が不完全・循環の場合も確定判定にしない。代替評価の欠落はUNKNOWNであり、候補なしの証明ではない。完全な候補集合が利用不可なら不成立。既知の別の必須不成立はANDを不成立にするが、未知だけを不成立に変換しない。対象と無関係な代替評価は結果へ影響しない。

構造成立と運転状態の保証は区別する。非除外要素の運転能力・安全性は推定しない。代替要素自身の旧必須条件を再要求せず、既存候補評価が候補自身の全必須条件を確認済みであることを前提とする。呼出元は同じ除外集合・世代・分析時点・完全性に基づいて候補を評価し、active / effective関係と予算を検証する。ここで連鎖置換は行わない。

追加19テストと関連126テストで、代替による成立復元、他の必須条件の維持、元要素に依存する不適切候補、未知と候補なし、不完全性、循環、複数除外、別対象の評価流用を検証した。AC-G05 / G06 / G09、T-R14 / R15の成立計算部分を支えるが、Graph検索・関係Evidence、SPOF分類、Tool / API接続は後続。受入基準全体の完了とは扱わない。
